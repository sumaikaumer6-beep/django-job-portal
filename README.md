# Django Job Portal

A Django based Job Portal web application with job listing, apply and admin features.

# Features
- Job Listing - All jobs display on homepage
- Job Detail Page - Full job description
- Job Apply Form - Users can apply for jobs
- Admin Panel - Add, edit, delete jobs
- Responsive Design with HTML and CSS

## Tech Stack
- **Backend**:Django, Python
- **Database**: SQLite3
- **Fronted**:HTML, CSS
- **Other**:Git, GitHub
